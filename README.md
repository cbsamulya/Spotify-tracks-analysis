# Spotify Tracks: Genre & Audio Feature Analysis

## About the Project

This project explores a dataset of approximately 114,000 Spotify tracks using Python, Pandas, and Power BI.

I cleaned the dataset, explored genre-level patterns, and compared selected audio features across six context-oriented genres: happy, party, sad, chill, study, and sleep.

## Tools

- Python
- Pandas
- Jupyter Notebook
- Power BI

## Dataset

The dataset contains information about Spotify tracks, including:

- Track and artist information
- Genre
- Popularity
- Energy
- Valence
- Danceability
- Acousticness
- Tempo
- Loudness
- Other audio features

## What I Did

- Checked and handled missing values
- Checked for duplicate records
- Cleaned unnecessary columns
- Worked with data types and numerical features
- Created a duration-in-minutes feature
- Explored average popularity across genres
- Compared audio features across selected context-oriented genres
- Created visualizations in Power BI

## Context-Based Analysis

For a focused comparison, I analyzed these six genres:

- Happy
- Party
- Sad
- Chill
- Study
- Sleep

The main features compared were:

- Energy
- Valence
- Danceability

## Power BI Dashboard

The final dashboard visualizes the average energy, valence, and danceability for the selected genres.

Some observations from the analysis:

- Party tracks showed consistently high average energy, valence, and danceability.
- Sad tracks showed relatively high average danceability within the selected groups.
- Sleep tracks showed the lowest average energy, danceability, and valence among the selected groups.

These are patterns observed in the dataset and are not intended to represent actual listener behavior.
